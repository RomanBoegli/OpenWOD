# OpenWOD 1.0.0

Released 26 October 2026.
Image: `ghcr.io/<owner>/<repository>:v1.0.0` (the lower-cased GitHub repository), digest to be filled in from the workflow's job summary after the manifest is published.
Database schema version 1.

## What is in it

- Six formats on one deterministic clock, solo or in pairs, with recorded voices and beeps.
- A household server: workouts, collections, movement edits and the session log live in SQLite on the server, every device sees the same library, and each device keeps a cache and an outbox for the time the server is away.
- Recovery after a reload, a closed tab or a killed browser, from checkpoints written on the device after every command and transition.
- One tab controls a session, with an explicit takeover from another tab or device.
- History with Repeat and score corrections that keep the earlier value.
- Workout files and packs with sharing provenance: reimports are recognised, newer revisions can replace, derivatives record their source.
- Backup through the SQLite backup API, a JSON export of everything, versioned migrations with a pre-migration backup, and a documented restore.
- 53 bundled workouts, a movement catalogue of 190 records, difficulty calibration, and the editor for every format.

## Supported browsers

Tested by the automated suite in WebKit, Firefox and Chromium engines.
Safari on macOS and iOS, Firefox and Chrome are the intended browsers.
Web Locks, BroadcastChannel and IndexedDB are required for recovery and single-tab control.
Browsers without them still play workouts, show "Not saving progress on this device", and never claim a recovery.

## Known limitations

- No login.
  Keep the server on a trusted network or behind an authenticating proxy.
- Session events are uploaded once, with the finished session, not streamed while playing.
- The JSON export can be read but not imported back.
  Restoring is done with the SQLite backup.
- The physical device checks are recorded per release by hand.

## Upgrading

This is the first release with a database.
A device that still holds a pre-1.0 library offers to move it to the server once, from the library page or from Settings → General.
