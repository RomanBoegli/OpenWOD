# OpenWOD 1.5.3

Image `ghcr.io/romanboegli/openwod:v1.5.3` (linux/amd64, linux/arm64), static site at [romanboegli.ch/OpenWOD](https://romanboegli.ch/OpenWOD/) and `openwod-static-v1.5.3.zip` attached.

## What's new

- Every valid workout opens in the editor, so imported files no longer lose Edit and Duplicate.
- The editor has rests of their own length, timed movements in For time and strength, and groups with their own rounds.
- New workout in Default: Full Body Fatburn Hour.
- Four new movements: Reverse Crunches, Lying Leg Raises, Supine Spinal Twist and Cobra Stretch.
- Block titles in Title Case.

## Upgrading

Set `APP_IMAGE` to `v1.5.3`, re-pull and redeploy. No migration, and rolling back to 1.5.2 is safe.
Unsaved editor drafts move to a new browser-storage key, which 1.5.2 does not read.
