The release workflow creates this release and appends the image digest line at the end of these notes by itself.

## What is in it

### Movements

- The movement catalogue has 259 records instead of 199, each with a recorded name in every voice pack.
- Weightlifting: clusters (squat clean thrusters), hang squat snatches, muscle snatches, snatch balance, clean pulls, snatch pulls, power and hang clean and jerks, behind-the-neck jerks, snatch-grip and deficit deadlifts, box and Zercher squats, back rack lunges.
- Dumbbell and kettlebell: dumbbell overhead squats, dumbbell hang clean and jerks, kettlebell high pulls, kettlebell windmills.
- Gymnastics: GHD hip extensions, GHD back extensions, hip and back extensions, strict toes-to-bar, toes-to-rings, windshield wipers, strict ring dips, ring support hold, strict bar muscle-ups, wall-facing handstand push-ups, L-sit pull-ups, kipping swings, scap pull-ups, hanging L-sit, skin the cat.
- Conditioning and HYROX style: triple-unders, lateral box jumps, tuck jumps, bear crawls, crab walks, battle ropes, tyre flips, yoke carry, sandbag squats, plate overhead lunges, lateral lunges, Cossack squats, wall sit, glute bridges, hip thrusts, swim, butt kicks.
- Core: flutter kicks, Superman hold, arch rocks, ab wheel rollouts, plank jacks.
- Warm-up: PVC pass-throughs, world's greatest stretch, cat-cow, leg swings, banded pull-aparts.

### Shorthand

- PC, PS, HPC, HPS, SC, FS, BS, PP, PJ, SJ and BBJ resolve to their movements, beside the shorthand that already worked (T2B, C2B, HSPU, KBS, WB, OHS, STOH, G2OH, DU, SDHP, BMU, C&J, RDL).
- Cal row, C2 row, Assault, Echo and Treadmill run resolve to the row, the bikes and the run.

### Equipment

- GHD, Battle rope, Tyre and Yoke join the equipment names, so "Only my equipment" knows what those movements need.
- GHD sit-ups now need a GHD.

## Supported browsers

Tested by the automated suite in WebKit, Firefox and Chromium engines, in both shapes.
Safari on macOS, iOS and iPadOS, Firefox and Chrome are the intended browsers.
Web Locks, BroadcastChannel and IndexedDB are required for recovery and single-tab control, and IndexedDB holds the library in the static site.
Browsers without them still play workouts, show "Not saving progress on this device", and never claim a recovery.

## Known limitations

- A movement you added yourself under the same name as a new bundled one can show twice under Settings → Movements.
  Tick both and merge them there.
- A movement in your own workouts written under another name than its record is read by the device voice, not a recorded one.
- The round donut steps aside on screens too narrow to show it beside the clock, and AMRAP and you-go-I-go blocks have none, because only the athletes know where they are in them.
- A deleted session cannot be brought back, and the JSON export does not carry the record of deleted sessions.
- An AMRAP with many more movements than three can still need the context view to scroll on a tablet in landscape, and says so with its "Long block" note.
- A mistyped path outside the app on GitHub Pages, such as `/OpenWOD/foo`, shows GitHub's own 404 page.
- Settings follow the last change, with no merging, and another device picks up a change on reload, focus or reconnect.
- The JSON export carries no settings.
  The SQLite copies under `/data/backups/` and Download backup under Settings → General carry them.
- The static site keeps its library and its settings per browser and per browser profile.
- No login.
  Keep the server on a trusted network or behind an authenticating proxy.
- Over plain HTTP the screen wake lock, the single-tab lock and persistent storage are unavailable, because browsers offer them in a secure context alone.
- The installed web app has no offline copy of itself and needs the server or the site to start.

## Upgrading

Set the stack's `APP_IMAGE` to the new tag or digest, re-pull and redeploy.
There is no migration: the database stays at schema version 3 and the household's data stays as it is.
The new movements come with the image, so workouts that already name them are recognised at once.

To roll back to 1.5.0, choose the old image.
Workouts keep their text, and the new movement names show as not in the catalogue again, read by the device voice.

Reload any device that still has the old page open, so it picks up the new build.

The static site needs no upgrade: GitHub Pages serves the new release as soon as it is published.
