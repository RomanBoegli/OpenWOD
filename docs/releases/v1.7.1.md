# OpenWOD 1.7.1

Image `ghcr.io/romanboegli/openwod:v1.7.1` (linux/amd64, linux/arm64), static site at [romanboegli.ch/OpenWOD](https://romanboegli.ch/OpenWOD/) and `openwod-static-v1.7.1.zip` attached.

## New Features

- Zoom in the training view: two buttons, or the + and - keys, draw the stations larger or smaller, and the clock takes the rest.
- In the context view the zoom applies to the game plan. Phones have no zoom.
- A Shortcuts link in the page footer opens the keyboard sheet.
- The fun buttons are on by default, and Settings → Training View lets you try both.
- Workout cards no longer show when a workout was last done. The workout's page still does.
- Settings: shorter hints for the timer's look, and centred count columns in the lists.

## Bugfixes

- A quick timer no longer says "Work" in the device voice after Get ready.
- On a narrow phone the training view's top row keeps its buttons inside the frame, where the fun buttons could push the last one out.

## Upgrading

Set `APP_IMAGE` to `v1.7.1`, or keep `latest`, then re-pull and redeploy.
No migration, and rolling back to 1.7.0 is safe.
A browser that already ran 1.7.0 keeps its Fun buttons setting, which was off unless you switched it on.
